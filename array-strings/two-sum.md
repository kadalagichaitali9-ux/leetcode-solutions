# Two Sum

**Difficulty:** Easy

**LeetCode Link:** https://leetcode.com/problems/two-sum/

## Approach

The program checks each pair of elements in the array and compares their sum with the target value. If the sum matches the target, the indices of those two elements are returned.

## Time Complexity

O(n²)

## Space Complexity

O(1)
